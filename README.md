# Pinterest Affiliate Marketing Automation App

This application automates the process of creating and managing Pinterest affiliate marketing campaigns. It helps users find trending Amazon products, generate affiliate links, create optimized pins, and track performance.

## Features

- Product research and discovery
- Affiliate link generation
- Pin creation and optimization
- Pinterest posting automation
- Analytics and performance tracking
- Mobile and web support

## Getting Started

1. Clone the repository
2. Install dependencies: `npm install`
3. Set up environment variables (see .env.example)
4. Run the development server: `npm run dev`

## Environment Variables

- `AMAZON_ASSOCIATE_ID`: Your Amazon Associate ID
- `AMAZON_ACCESS_KEY`: Amazon API access key
- `AMAZON_SECRET_KEY`: Amazon API secret key
- `PINTEREST_APP_ID`: Pinterest app ID
- `PINTEREST_APP_SECRET`: Pinterest app secret

## Technologies

- Next.js
- TypeScript
- Tailwind CSS
- Amazon Product Advertising API
- Pinterest API
